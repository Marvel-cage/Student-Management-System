# 🎓 Student Management System (Python)

## Second project given to me by my Computer Teacher before he left. Started in JSS3 finished not so long after he left. Completed using my laptop in late 2025

## 📖 What it does
- Add new students (Name, Class, Scores)
- View all students
- Search student by name
- Calculate average score & grade (A-F)
- Save records to file
- Head Boy use-case: I used logic from my duties managing student records

## 🛠️ How it works
- Pure Python, no external libraries
- Uses lists & dictionaries to store student data
- File handling to save data permanently
- Loop + Functions for menu

## ▶️ How to run
```bash
python student_management_system.py
